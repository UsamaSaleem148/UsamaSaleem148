### ⚡ What I do

- **AI & LLM engineering:** I ship LLM features to production using OpenAI, Claude and Gemini, including tool calling, structured outputs, agents and MCP servers.
- **Machine learning:** I train and serve models in Python with PyTorch, TensorFlow, scikit-learn and Hugging Face.
- **Full stack:** I build typed web apps with Next.js, React and TypeScript on the front, and Node.js, Spring Boot and PostgreSQL on the back.
- **Cloud:** I run serverless, event-driven systems on AWS, written as Terraform and deployed through CI/CD.

6+ years of building software, from the first commit to production.
